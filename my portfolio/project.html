First project

Mind Quest App is a dynamic and interactive quiz-based web application built with the aim of making learning fun, engaging, and effective. This application allows users to test their knowledge across various topics by participating in category-based multiple-choice quizzes. The app is designed with a clean, user-friendly interface using HTML, CSS, and JavaScript on the frontend, while the backend is powered by Node.js and MySQL to ensure secure data handling, user authentication, and storage of quiz data. Users can choose a category (like Programming or Mathematics), and the app fetches a set of relevant multiple-choice questions. Each quiz session includes a timer to keep the experience challenging and exciting. At the end of each session, the user’s score is displayed along with detailed feedback on their performance.


second project

Blinkit Data Analysis is a project focused on cleaning, transforming, and visualizing Blinkit’s real-world data. It includes removing duplicates, handling missing values, applying formulas for sales and delivery insights, and visualizing trends like top products, pricing, and performance. The goal is to extract useful insights to support better business decisions.
